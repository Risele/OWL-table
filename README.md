# OWL-Tables

OWL-Tables создаёт макросы FBD и ST для OwenLogic по таблице входов и выходов. Таблица задаёт, например, при каких сигналах разрешён пуск или какую частоту и выдержку времени выдать приводу.

## Режимы

| Режим | Как работает макрос | Пример |
|---|---|---|
| Таблицы | Выбирает набор параметров по номеру записи `ID`. Номера могут идти с пропусками. | Номер рецепта задаёт массу порции, число циклов и признак промывки. |
| Bool | Вычисляет логический выход и его инверсию по состоянию 1–16 дискретных входов. Для пропущенной комбинации прямой выход равен 0. | Два из трёх датчиков должны подтвердить наличие продукта. |
| Комбинированный | Выбирает набор параметров по состоянию 1–16 дискретных входов. | Контакты переключателя задают направление и скорость привода. |

В табличном и комбинированном режимах одна запись может содержать параметры типов `BOOL`, `UDINT` и `REAL`. Выход `Valid` равен 1, если макрос нашёл подходящую запись, и 0, если совпадения нет.

Для дискретного входа знак `X` означает, что в этой строке допустимы и 0, и 1. В Bool функцию можно задать списком правил или полной таблицей комбинаций. При генерации программа автоматически минимизирует логику, сохраняя значение выхода для каждой комбинации.

## Редактор

Входы расположены слева, выходы справа. У порта есть короткое имя и отдельный комментарий. Например, вход `I1` сохраняет своё имя в макросе, а в заголовке столбца видна подпись «Готовность привода». К каждой записи можно добавить примечание.

В режимах Bool и Комбинированный связанные входы можно выделить одним из 12 светлых цветов. Например, одним цветом отметить команды оператора, другим — сигналы датчиков. Строки и столбцы можно переставлять. При переносе столбца вместе с ним перемещаются значения, комментарий и цвет.

У каждой вкладки свой документ. Между Bool и комбинированным режимом можно переносить входы, их комментарии и цвета. Между табличным и комбинированным режимами можно переносить выходные параметры, значения и примечания к записям.

## Импорт и экспорт

Каждый режим поддерживает импорт и экспорт отдельных книг Excel (`.xlsx`). Цвета дискретных входов сохраняются в книге. Генератор выпускает FBD (`.tple`), ST (`.fbst`) или оба формата. В каждый макрос OWL-Tables встраивает исходную таблицу. Её можно восстановить для редактирования из одного файла макроса.

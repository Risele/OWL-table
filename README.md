# Table2FBD

Программка, которая формирует «Таблицы параметров» на FBD и ST из Excel для OwenLogic.

Эдакий многоканальный мультиплексор: на входе один номер из таблицы, на выходе —
набор значений. Поддерживаются BOOL, REAL и UDINT. Одна строка — одна запись,
каждый столбец — отдельный параметр.

На выходе получается готовый для импорта макрос. Если записей много, можно
разбить таблицу на подмакросы, например, по диапазонам номеров 0–9, 10–19 и дальше.
Сводный макрос сам выберет нужную группу по входному номеру.

Есть встроенный редактор, так что таблицу можно создать и поправить прямо
в программе. Устанавливать Excel не нужно. Можно и без интерфейса обновлять
макросы из файла `.xlsx` — подходящий батник идёт в комплекте.

Изначально написана на Python, затем появилась версия на C++. Исходники обеих
версий находятся здесь, в репозитории. Готовая программа для Windows —
в разделе **Releases**, архив `*-cpp-win32.zip`. Распакуйте архив и запустите `Table2FBD.exe`.

# Как вернуть макрос в редактор

Выберите **Файл → Открыть макрос для редактирования…** и укажите `.tple` (FBD) или `.fbst` (ST). OWL-Tables откроет нужную вкладку и восстановит исходную таблицу. Достаточно одного файла макроса. Если на вкладке уже есть несохранённые изменения, редактор предложит их сохранить. Команда **Сохранить…** позволяет записать открытую таблицу в книгу Excel.

## Что восстанавливается

| Режим | Что возвращается в редактор |
|---|---|
| Bool | Дискретные входы в заданном порядке, их комментарии и цвета, имена прямого и инверсного выходов. Для правил сохраняются исходные `0`, `1`, `X`, значение выхода и примечания. Для таблицы всех комбинаций сохраняются значения Q, видимые строки и их порядок. |
| Таблицы | Имена, типы и описания параметров, ID наборов, значения ячеек, примечания и порядок записей. |
| Комбинированный | Дискретные входы и их цвета, описания столбцов, условия выбора строк, выходные параметры, значения и примечания. |

Также восстанавливаются имя макроса, выбор FBD и ST и шаги группировки табличных макросов. Сохраняется таблица, которую автор передал генератору. Например, правило «Пуск = 1, Готовность = X» вернётся одной строкой, даже если решатель полностью исключил вход «Готовность» из выражения.

## Где найти таблицу в OwenLogic

В **ST** откройте исходный текст и перейдите в конец. После `END_FUNCTION_BLOCK` корневого блока стоит подпись «Сгенерировано OWL-Tables», затем идут строки `// LWB1 …`. Все объявления и операторы расположены выше. Если есть вложенные блоки, генератор помещает их перед корневым. Для открытия в редакторе выберите `.fbst`.

В **FBD** откройте описание корневого макроса. После обычного описания стоит подпись «Сгенерировано OWL-Tables», затем идут строки `LWB1 …`. Схемные элементы для хранения таблицы не нужны. Служебные строки также записываются в описание макроса в каталоге. При выпуске обоих форматов каждый файл содержит полную таблицу.

## Если файл редактировали вручную

Если отпечаток ST или FBD изменился, редактор предложит открыть таблицу, сохранённую при генерации. Позднейшие ручные изменения операторов и соединений придётся внести в таблицу самостоятельно.

Если вы выбрали сторонний макрос или удалили служебный комментарий целиком либо частично, редактор покажет «Не удалось распознать макрос». Текущая вкладка и введённые данные сохранятся. Для макросов прежних версий без `LWB1` используйте исходную книгу.

## Формат и ограничения

В строке после подписи записаны версия `LWB1`, способ упаковки (`Z` для zlib, `R` для несжатых данных), длина документа в байтах, CRC32, отпечаток определений и число частей. Дальше идут пронумерованные части длиной до 192 символов данных. Исходный документ хранится как компактный JSON в UTF-8. Генератор выбирает более короткую из сжатой и несжатой записей и переводит её в Base64url. Для плотной таблицы Bool значения Q занимают один бит на комбинацию, то есть 8192 байта при 16 входах до текстового кодирования. Порядок строк и комментарии хранятся отдельно от этих битов.

Если сгенерировать макрос `EditableCombined` из книги «Пуск по готовности» с шагом группы 1, служебные строки FBD вместе с подписью занимают 479 байт. Размер зависит от содержимого таблицы.

Генератор ограничивает полное описание FBD величиной **65 536 байт UTF-8**, включая обычный текст и служебные строки. При превышении показывает требуемый размер и предел. В этом случае можно выбрать только ST или сократить комментарии. Для обоих форматов предел исходного упаковываемого документа до zlib составляет **16 МиБ**. Проверка CRC32 обнаруживает повреждение данных, а отдельный отпечаток служит для обнаружения изменений в самом макросе.

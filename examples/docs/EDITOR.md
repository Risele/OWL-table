# Работа с таблицами

## Выбор режима

В режиме **Таблицы** вход `ID` задаёт номер записи. Например, для ID 7 можно задать скорость 50,5 и разрешение пуска. Когда макрос находит запись, он выдаёт её параметры и устанавливает `Valid = 1`.

В режиме **Bool** каждая строка задаёт условие для логического выхода. Укажите `0` или `1` для каждого входа. Поставьте `X`, если состояние входа может быть любым. Если комбинация отсутствует, выход равен 0. Имена прямого и инверсного выходов можно изменить на вкладке **Входы**.

В режиме **Комбинированный** набор дискретных сигналов выбирает запись с параметрами. Задайте сигналы на вкладке **Входы**. Добавьте параметры на вкладке **Выходы**. На вкладке **Записи** укажите условия выбора и значения параметров. Если ни одно условие не выполнено, выход `Valid` равен 0.

## Редактирование

Слева от толстой вертикальной линии расположены входы. Справа расположены выходы и примечания. Чтобы прочитать длинный комментарий к порту, откройте перечень входов или выходов.

Чтобы выделить группу дискретных сигналов, выберите вход и задайте **Цвет столбца**. При перестановке входа его значения, комментарий и цвет перемещаются вместе с ним.

Каждая вкладка хранит отдельный документ. Звёздочка в заголовке окна указывает на несохранённые изменения. Чтобы сохранить активный документ в книгу Excel, нажмите **Ctrl+S**.

## Перенос между вкладками

| Переход в любом направлении | Какие данные можно перенести |
|---|---|
| Таблицы ↔ Комбинированный | Параметры, их значения и примечания к записям. Программа сопоставляет параметры по имени, записи по порядку. |
| Bool ↔ Комбинированный | Дискретные входы, их комментарии и цвета. Программа сопоставляет входы по имени. |
| Bool ↔ Таблицы | Каждая вкладка сохраняет свои данные отдельно. |

Выберите **Да**, чтобы объединить данные. Заполненные значения источника обновят совпадающие ячейки. Дополнительные строки и поля сохранятся. После переноса проверьте условия выбора в новых строках комбинированной таблицы. Команда **Правка → Отменить** отменяет перенос целиком.

Выберите **Нет**, чтобы открыть вкладку с её текущими данными. Программа запомнит ответ для этого направления до изменения исходных данных. Выберите **Отмена**, чтобы остаться на текущей вкладке.

## Обмен с Excel

Для каждого режима используйте отдельную книгу `.xlsx`. Нажмите **Ctrl+O** на вкладке нужного режима. Если в книге несколько листов, выберите **Файл → Лист книги**. Готовые задачи доступны через **Справка → Примеры**. [Каталог книг и макросов](../examples/README.md)

| Книга | Входные столбцы | Выходные столбцы |
|---|---|---|
| Две скорости привода | Один столбец типа `ID` | Параметры типов `REAL`, `UDINT`, `BOOL` |
| Разрешение пуска | От 1 до 16 столбцов типа `BOOL_IN` | `BOOL_OUT` и `BOOL_NOT` |
| Пуск по готовности | От 1 до 16 столбцов типа `INPUT` | Параметры типов `REAL`, `UDINT`, `BOOL` |

В первой строке листа укажите описания столбцов. Во второй строке укажите типы. В третьей строке укажите имена портов. Вводите записи с четвёртой строки. Для примечаний используйте столбец типа `COMMENT` с пустым именем порта. Выход `Valid` программа создаёт сама.

## Создание и повторное открытие макроса

1. Введите имя макроса на нижней панели.
2. Выберите FBD, ST или оба формата.
3. Нажмите **Создать макросы…**.
4. Укажите место сохранения.

В библиотеке OwenLogic корневой макрос находится в группе `Boolean` для режима Bool и в группе «Таблицы параметров» для двух остальных режимов. Все вложенные макросы находятся в группе `OWL_Tables_auto` соответствующего типа (ST или FBD).

Чтобы вернуться к таблице, откройте созданный файл `.tple` или `.fbst` через **Файл → Открыть макрос для редактирования…**. [Как программа восстанавливает таблицу](MACRO_IMPORT.md)

# Сборка OWL-Tables для Windows

## Сборка редактора

1. Установите C++Builder 11 с компилятором Win32, VCL и RTL.
2. Распакуйте архив исходников или откройте рабочую копию Git.
3. Запустите PowerShell в папке с файлом `README.md`.
4. Выполните команду сборки.

```powershell
.\boolean\build.ps1 -Unified
```

По умолчанию сценарий ищет C++Builder в папке `C:\Program Files (x86)\Embarcadero\Studio\22.0`. Если среда установлена в другой папке, укажите путь через параметр `-Bds`.

5. Запустите `unified\dist\OWL-Tables\OWL-Tables.exe`.
6. Откройте **Справка → Примеры** и выберите пример для нужного режима.

## Подготовка выпуска

Для упаковки нужны Git и Python 3.9 или новее. Работайте в копии Git. Зафиксируйте изменения для выпуска, затем выполните команду.

```powershell
python unified/package_release.py
```

Сценарий берёт файлы из текущего коммита, распаковывает архив исходников и собирает из него программу. В папке `release/OWL-Tables-<версия>` появятся архив исходников, архив для Windows и файл контрольных сумм `SHA256SUMS.txt`. Номер версии задан в `boolean/version.hpp`.

Чтобы проверить загруженный архив, вычислите его SHA-256. Сравните результат со строкой для этого файла в `SHA256SUMS.txt`.

```powershell
Get-FileHash .\OWL-Tables-*-win32.zip -Algorithm SHA256
```

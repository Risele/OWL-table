# Компоненты OWL-Tables

Код OWL-Tables распространяется по лицензии 0BSD. Текст лицензии находится в файле `LICENSE`.

| Компонент | Назначение | Условия использования |
|---|---|---|
| nlohmann/json 3.11.3 | Чтение и запись данных JSON | MIT, файл `json-LICENSE.txt` |
| pugixml 1.14 | Чтение и запись данных XML | MIT, файл `pugixml-LICENSE.txt` |
| C++Builder 11, VCL и RTL | Интерфейс Windows и стандартные функции программы | Условия лицензии Embarcadero |

Тексты лицензий MIT находятся в папке `licenses` дистрибутива и в папке `cpp/vendor` исходников.

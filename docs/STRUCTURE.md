# Состав репозитория

```text
Table2FBD/
  README.md                  краткое описание и запуск программы
  LICENSE                    лицензия 0BSD для собственного кода
  THIRD_PARTY_NOTICES.md      сведения о сторонних компонентах
  Generate.bat               консольный запуск готовой программы
  release_manifest.json      явные списки файлов исходных архивов
  python/                    приложение Python и его проверки
    requirements.txt         зависимости Python
    build.ps1                сборка Python в EXE
  cpp/                       приложение C++, сборка и проверки
    vendor/                  исходники JSON/XML и лицензии MIT
  tools/
    package_release.py       упаковка трёх архивов для релиза
    check_st_import.ps1      проверка ST через установленную OwenLogic
  assets/                    нейтральная таблица, значок, лицензии Python
  checks/owen_fbd/            дополнительная проверка установленной OwenLogic
  docs/
    BAT.md                   работа с батником
    USAGE.txt                существующая справка по использованию
    BUILD.md                 отдельная инструкция по сборке и проверкам
    RELEASING.md             состав и порядок публикации релиза
    STRUCTURE.md             этот файл
```

Основной `README.md` содержит краткое описание и сведения о запуске программы.
Исходники разделены по языкам: `python/` и `cpp/`. Общие ресурсы находятся
в `assets/`, средства упаковки — в `tools/`. Команды запуска и сборки из корня
репозитория приведены в `docs/BUILD.md`.

В репозиторий не входят проекты пользователя, исходные рабочие таблицы,
декомпилированные файлы, библиотеки OwenLogic, C++Builder и готовые EXE.
В `assets/Template.xlsx` используются только нейтральные демонстрационные данные.

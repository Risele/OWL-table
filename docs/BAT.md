# Работа с батником

`Generate.bat` обновляет макросы из `.xlsx`, не открывая окно программы.
Самый простой способ — перетащить на него файл таблицы. По умолчанию рядом
с таблицей появятся два файла: `.tple` для FBD и `.fbst` для ST.
Рядом с батником должен лежать `Table2FBD-cli.exe` из архива программы.

## Если таблица всегда одна

Откройте `Generate.bat` в текстовом редакторе и задайте пути в начале файла:

```bat
set "INPUT_FILE=Таблицы\Режимы.xlsx"
set "OUTPUT_FILE=Макросы\Режимы"
set "MACRO_NAME=FanModes"
```

Теперь достаточно запускать BAT двойным щелчком. Если `OUTPUT_FILE` пустой,
используются имя и папка исходной таблицы. Расширения добавляются по выбранным
форматам. `MACRO_NAME` — имя макроса внутри OwenLogic, оно задаётся отдельно.

При перетаскивании файл заменяет `INPUT_FILE` только на время этого запуска.
Остальные настройки, в том числе `OUTPUT_FILE`, продолжают действовать.

## Форматы и группы

```bat
set "OUTPUT_FORMAT=BOTH"
set "GROUP_STEP=10"
set "SINGLE_MACRO=0"
set "ST_GROUP_STEP=10"
set "ST_SINGLE_MACRO=0"
```

`OUTPUT_FORMAT`: `BOTH` — оба формата, `FBD` или `ST` — только один.
`GROUP_STEP` и `SINGLE_MACRO` относятся к FBD, настройки с `ST_` — к ST.

`SINGLE_MACRO=0` разбивает записи на группы по ID, `SINGLE_MACRO=1` собирает
всё в один макрос. Для ST смысл тот же. Шаг 10 даёт группы 0–9, 10–19 и далее.

`SHEET_NAME` можно оставить пустым: выбирается лист «Данные», а если его нет —
первый лист книги.

## Запуск из командной строки

```bat
Generate.bat "Таблицы\Режимы.xlsx"
Generate.bat "Таблицы\Режимы.xlsx" --st
Generate.bat --fbd
```

Ключи `--st` и `--fbd` имеют приоритет над `OUTPUT_FORMAT`.
За один запуск обрабатывается одна таблица. Остальные параметры меняются
в начале BAT; для передачи всех настроек ключами используйте консольный EXE,
как описано в [подробной справке](USAGE.txt).

## Пути и автоматический запуск

Относительные пути **в настройках BAT** отсчитываются от папки самого батника.
Относительный путь **в аргументе команды** — от текущей папки командной строки.
Поддерживаются русские буквы, пробелы и переходы через `..\`.

Сохраняйте BAT в UTF-8 без BOM и оставляйте кавычки в командах `set`.
Знак `%` в пути, записанном внутри BAT, нужно удвоить: `%%`.

Для запуска по расписанию или из другого скрипта отключите ожидание клавиши:

```bat
set "PAUSE_AT_END=0"
set "PAUSE_ON_DROP=0"
```

Из другого BAT вызывайте его через `call`. Код завершения `0` означает успех,
`1` — ошибку данных или работы с файлами, `2` — ошибку параметров.
